# 🏥 QNow
### AI-Powered Smart Patient Queue Management System

> **One Link. Real Answers. Zero Anxiety.**

QNow is an AI-powered healthcare web application that transforms the patient waiting experience by providing real-time queue tracking, intelligent wait-time predictions, and proactive notifications—all through a simple link with **no app installation or login required**.

---

## 🚀 Problem Statement

Patients often spend hours waiting in hospitals without any visibility into when they'll actually be seen. Traditional token systems provide little useful information, leading to frustration, uncertainty, and missed appointments.

QNow addresses this challenge by making hospital queues transparent, predictable, and stress-free.

---

## 💡 Solution

QNow provides patients with a live queue tracker immediately after check-in.

Instead of waiting blindly, patients receive:

- 📍 Live queue position
- 🧠 AI-estimated waiting time
- 🔔 Smart notifications
- 📱 Instant browser access via SMS link

No application download.
No registration.
No login.

# 🌟 Key Features

### 📍 Live Queue Position

Patients always know exactly where they are in the queue.

---

### 🧠 AI Wait Prediction

Estimated waiting time is calculated using factors like:

- Appointment Type
- Queue Length
- Time of Day
- Historical Visit Patterns

---

### 📲 Zero Friction Access

No app downloads.

No account creation.

Simply open the SMS link.

---

### 🔔 Smart Alerts

Patients receive notifications when:

- Their turn is approaching
- The doctor is delayed
- Queue status changes

---

### 👩‍💼 Reception Dashboard

Receptionists can:

- Add patients
- Update queue
- Mark appointments completed
- Automatically notify waiting patients

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/vaibhavitej-a11y/Qnow.git
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

```bash
cd backend
pip install -r requirements.txt
python app.py
```
